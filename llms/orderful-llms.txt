- [Create a Transaction](https://docs.orderful.com/reference/transactioncontroller_create.md): Creates a Transaction. Only one Transaction can be posted at a time. For guidance on how to use this page, see the <a href="https://docs.orderful.com/docs/create-a-transaction#make-an-api-call-using-our-api-explorer" target="_blank">Create a Transaction guide</a>. Check the status field to determine if the transaction was successfully accepted for processing or failed.
- [Accept a transaction delivery.](https://docs.orderful.com/reference/transactioncontroller_handledeliveryapproved.md): Accepts the specified transaction delivery. This link is included when a Transaction is retrieved from a <a href="https://docs.orderful.com/reference/inboxcontroller_list" target="_blank">Inbox</a> or via an <a href="https://docs.orderful.com/docs/inbound-http" target="_blank">Inbound HTTP Communication Channel</a>.If this Delivery is the most recent one associated with a Transaction, this will update the Transaction's `deliveryStatus` to `DELIVERED`.If this Delivery is associated with one or more Transactions in a inbox, this will also remove the Transactions from that inbox.
- [Fail a transaction delivery.](https://docs.orderful.com/reference/transactioncontroller_handlefaildeliveryrequest.md): Fails the specified transaction delivery. This link is included when a Transaction is retrieved from a <a href="https://docs.orderful.com/reference/pollingcontroller_list" target="_blank">Inbox</a> or via an <a href="https://docs.orderful.com/docs/inbound-http" target="_blank">Inbound HTTP Communication Channel</a>.  If this Delivery is the most recent one associated with a Transaction, this will update the Transaction's `deliveryStatus` to `FAILED`.  If this Delivery is associated with one or more Transactions in a inbox, this will also remove the Transactions from that inbox.
- [Get a Delivery.](https://docs.orderful.com/reference/transactioncontroller_getdelivery.md): Returns the specified transaction delivery. Links to Delivery objects are available in Transactions retrieved from a <a href="https://docs.orderful.com/reference/pollingcontroller_list" target="_blank">Inbox</a> or via an <a href="https://docs.orderful.com/docs/inbound-http" target="_blank">Inbound HTTP Communication Channel</a>.
- [Inbox](https://docs.orderful.com/reference/inboxcontroller_list.md): Retrieves the Transactions from the specified Inbox.  **Note:** The `inboxId` can be found by logging in to [ui.orderful.com](https://ui.orderful.com) and navigating to "Communication Channels".

- [Create a Transaction](https://docs.orderful.com/reference/transactioncontrollerv3_create.md): Creates a Transaction using the v3 API format. Either a `message` or `summary` must be provided, but not both. For guidance on how to use this endpoint, see the <a href="https://docs.orderful.com/docs/create-a-transaction" target="_blank">Create a Transaction guide</a>.
- [Create a raw Transaction](https://docs.orderful.com/reference/transactioncontrollerv3_createraw.md): Creates a Transaction from a raw document. The request body should contain the raw document content (e.g. X12, XML, CSV). Routing metadata is provided via request headers rather than in the body.  > 🚧 Try It! playground limitation > > The in-page **Try It!** playground on this reference can only exercise `application/json` request bodies. If you are testing or experimenting with `application/xml`, `text/xml`, `text/csv`, `application/pdf`, `image/jpeg`, or `text/plain` payloads, use cURL or an HTTP client such as Postman for your ad-hoc requests. Your production integration is unaffected — this applies only to the in-browser Try It! tool. The endpoint itself accepts every supported content type from any HTTP client.
- [List Transactions](https://docs.orderful.com/reference/transactioncontrollerv3_list.md): Returns an array of Transactions sorted in descending order by their creation date. A maximum of 100 Transactions will be returned at a time.
- [Get a Transaction](https://docs.orderful.com/reference/transactioncontrollerv3_getbyid.md): Returns the specified Transaction.
- [Get a Transaction Message](https://docs.orderful.com/reference/transactioncontrollerv3_getmessage.md): Returns the specified Transaction's message content.
- [Create an Acknowledgment](https://docs.orderful.com/reference/transactioncontrollerv3_acknowledgetransaction.md): Creates an acknowledgment with the specified status for the specified Transaction.
- [Get an Acknowledgment](https://docs.orderful.com/reference/transactioncontrollerv3_getacknowledgment.md): Returns the acknowledgment for the specified Transaction.
- [Confirm the delivery of a set of Transactions](https://docs.orderful.com/reference/transactioncontrollerv3_confirmdelivery.md): Orderful will soon deprecate this endpoint. After retrieving Transactions from a Polling Bucket, you should use the Delivery API to mark a Delivery as <a href="https://docs.orderful.com/reference/deliverycontroller_handledeliveryapproved" target="_blank">Approved</a> or <a href="https://docs.orderful.com/reference/deliverycontroller_handlefaildeliveryrequest" target="_blank">Failed</a>. This will automatically remove the Transaction from the Bucket.
- [Get Transactions from Poller Bucket](https://docs.orderful.com/reference/pollingcontroller_list.md): Retrieves the Transactions from the specified Poller Bucket.
- [Remove a set of Transactions from a Bucket](https://docs.orderful.com/reference/pollingcontroller_confirmdelivery.md): Orderful will soon deprecate this endpoint. After retrieving Transactions from a Polling Bucket, you should use the Delivery API to mark a Delivery as <a href="https://docs.orderful.com/reference/deliverycontroller_handledeliveryapproved" target="_blank">Approved</a> or <a href="https://docs.orderful.com/reference/deliverycontroller_handlefaildeliveryrequest" target="_blank">Failed</a>. This will automatically remove the Transaction from the Bucket.
- [Approve a Delivery](https://docs.orderful.com/reference/deliverycontroller_handledeliveryapproved.md): Approves the specified Delivery. This link is included when a Transaction is retrieved from a <a href="https://docs.orderful.com/reference/pollingcontroller_list" target="_blank">Poller Bucket</a> or via an <a href="https://docs.orderful.com/docs/inbound-http" target="_blank">Inbound HTTP Communication Channel</a>.   If this Delivery is the most recent one associated with a Transaction, this will update the Transaction's `deliveryStatus` to `DELIVERED`.  If this Delivery is associated with one or more Transactions in a Poller Bucket, this will also remove the Transactions from that Bucket.
- [Fail a Delivery](https://docs.orderful.com/reference/deliverycontroller_handlefaildeliveryrequest.md): Fails the specified Delivery. This link is included when a Transaction is retrieved from a <a href="https://docs.orderful.com/reference/pollingcontroller_list" target="_blank">Poller Bucket</a> or via an <a href="https://docs.orderful.com/docs/inbound-http" target="_blank">Inbound HTTP Communication Channel</a>.   If this Delivery is the most recent one associated with a Transaction, this will update the Transaction's `deliveryStatus` to `FAILED`.  If this Delivery is associated with one or more Transactions in a Poller Bucket, this will also remove the Transactions from that Bucket.
- [Convert Data Between Formats](https://docs.orderful.com/reference/conversioncontroller_convertdata.md): This endpoint will convert JSON into X12, or X12 into JSON. Set the "Content-Type" header as the format you are sending, and the "Accept" header as the format you would like to receive back.

For more information, see the <a href="https://docs.orderful.com/docs/generate-shipping-label" target="_blank">Create a Label guide</a>. Supports single label or batch generation.
